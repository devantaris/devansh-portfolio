└──────────────────────────┬─────────────────────────────┘
                           │
             ┌─────────────┴─────────────┐

## 🚀 Getting Started

### Prerequisites
- **Node.js:** v20.x or higher
- **npm:** v10.x or higher

### Installation
```bash
git clone https://github.com/devantaris/devansh-portfolio.git
cd devansh-portfolio
npm install
```

### Development
Start the local Next.js development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser. The root URL automatically serves the blueprint engine.

### Syncing Live Data Manually
To test or trigger the automated scrapers locally:
```bash
# Fetch latest CodeChef stats
node scripts/update-codechef.mjs

# Fetch rolling GitHub contribution cells
node scripts/fetch-github-contributions.mjs
```

### Production Build
The build pipeline automatically refreshes external telemetry before generating the static export:
```bash
npm run build
```
This executes:
1. `node scripts/update-codechef.mjs` — Scrapes and writes latest contest standings.
2. `node scripts/fetch-github-contributions.mjs` — Parses rolling annual commits.
3. `next build` — Generates optimized static HTML/CSS/JS export in `out/`.
4. `node scripts/fix-basepath.mjs` — Copies `blueprint.html` to `out/index.html` and normalizes asset paths.
